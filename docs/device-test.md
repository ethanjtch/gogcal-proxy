# 手机真机验收清单

## 一、加账户 / 换密码

**已经是加过账户的（只改了密码）**：设置 → 日历 → 账户 → 点你的 gogcal 账户 → 账户 → 密码，填新的 `GATE_PASS`。会弹"无法验证账户"是正常的，重填后等 10 秒。

**从零加**：设置 → 日历 → 账户 → 添加账户 → 其他 → 添加 CalDAV 账户

| 字段 | 值 |
|---|---|
| 服务器 | `<你的域名>`（不要带 `https://`、不要带路径） |
| 用户名 | 你的 `GATE_USER` |
| 密码 | 新设的 `GATE_PASS` |
| 描述 | `gogcal` |

**「使用 SSL」必须开着**，端口留空（默认 443）。点下一步后它会自动走
`/.well-known/caldav` → `/caldav/v2/` → principal → 日历列表，几秒内出现日历勾选框。

顺手把设置 → 日历 → 账户 → 获取新数据 → **推送** 打开，后面测试不用干等。

## 二、验收清单（按顺序做，每条都记结果）

| # | 动作 | 期望 |
|---|---|---|
| 1 | 首次同步 | 日历 App 里出现 Google 的各日历和已有事件 |
| 2 | 手机新建事件（1 小时后） | 网页 Google 日历 30 秒内出现 |
| 3 | 网页改那个事件的时间 | 手机 30 秒内变 |
| 4 | 手机删除它 | 网页消失 |
| 5 | 建**全天**事件 | 两端一致，日期不偏一天 |
| 6 | 建**每周重复**事件 | 两端都是重复 |
| 7 | 建**跨零点**事件（23:30–00:30） | 两端时长一致，不出现 24:30 |
| 8 | **飞行模式**下改事件标题 → 关飞行模式 | 改动成功上传（这条专门测 PUT body 重放） |
| 9 | 连续快速改同一个事件 5 次 | 最终两端一致，无 "日历无法同步" 弹窗 |

第 5–9 条是最容易暴露问题的地方：全天事件的 `VALUE=DATE`、重复事件的 `RRULE`、跨零点的时区处理、以及断网重连后的 PUT。

## 三、失败时看什么

在电脑上开着日志，手机操作，日志会实时打出手机发的每个请求：

```bash
cd /Users/ethanchen/Developer/gogcal-proxy
./node_modules/.bin/wrangler tail gogcal-proxy --format pretty --status error
```

只看报错的请求。判断方法：

| 现象 | 含义 |
|---|---|
| 加账户时 401 | 用户名/密码错，或 `GATE_*` Secret 没生效 |
| 能加账户但**没有日历** | principal / home-set 的 PROPFIND 失败 |
| 能看**不能改** | PUT 被拒，多半是 ETag / `If-Match` |
| 502 且日志有 `refresh_failed` | refresh token 失效，要重新走 `/__auth` |
| 手机端 "无法连接服务器" | 只可能是域名/网络，与代理逻辑无关 |

日志里有 `apidata.googleusercontent.com` 出现在响应里，说明路径改写漏了——这种情况直接告诉我。
